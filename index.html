Zum Start fährt schon etwa die Hälfte der Fahrzeuge als Gegenverkehr auf der linken Spur. Fasse ein Fahrzeug an und ziehe es an eine andere Stelle — die Straßenseite beim Loslassen bestimmt seine Fahrtrichtung. Platziere Ampeln und Vorfahrtsschilder frei auf der Strecke; Ampeln schaltest du manuell per Klick zwischen Rot und Grün.

Klicke auf die Straße, um zu platzieren — je nachdem, auf welcher Seite du klickst, wirkt das Element nur auf diese Fahrtrichtung. Nahe einer Kreuzung rastet die Platzierung automatisch genau auf den Kreuzungsarm ein. Klicke ein vorhandenes Element an, um es zu entfernen. Außerhalb des Platzierungsmodus schaltet ein Klick auf eine Ampel sie zwischen Rot und Grün um. An einer Kreuzung erzwingt eine Vorfahrtsstraße freie Fahrt für ihre Seite, während Vorfahrt-achten-Schilder auf der Gegenseite immer warten müssen; ohne Schilder gilt automatisch „wer zuerst da ist". Ein Fahrzeug lässt sich zusätzlich anfassen und verschieben — die Straßenseite beim Loslassen bestimmt die Fahrtrichtung.

Was hier passiert: Jedes Fahrzeug reagiert nur auf den Abstand und die Geschwindigkeit des Vordermanns oder einer roten Ampel auf der eigenen Straßenseite (IDM-Formel von Treiber et al.) — Gegenverkehr auf der linken Spur wird dabei komplett unabhängig von der rechten Spur simuliert, und eine Ampel oder ein Schild wirkt jeweils nur auf die Fahrtrichtung, auf deren Seite es platziert wurde. Löst sich eine Blockade durch eine Ampel, beschleunigt das Fahrzeug für einige Sekunden spürbar kräftiger, so wie Autofahrer es beim Anfahren tun — danach klingt der Effekt wieder ab. Es gibt keine zentrale Steuerung: Wähle ein Fahrzeug aus und greife manuell ein, verschiebe ein Fahrzeug an eine andere Stelle, oder platziere Ampeln auf der Strecke — all das reicht, damit sich eine sich selbst erhaltende Stauwelle bildet. Das ist der klassische „Phantomstau".

Kreuzung (Doppelschleife): An der einen echten Kreuzung der Achterbahn-Strecke treffen bis zu vier Verkehrsströme aufeinander (beide Fahrtrichtungen auf beiden Schleifen). Ohne Beschilderung gilt automatisch „wer zuerst nah genug herankommt" — wie eine unbeschilderte Kreuzung im echten Verkehr. Platzierst du eine Vorfahrtsstraße (gelbe Raute) auf einer Seite, bekommt diese Fahrtrichtung dort immer bedingungslos Vorfahrt; ein Vorfahrt-achten-Schild (rotes Dreieck) sorgt umgekehrt dafür, dass diese Richtung sich immer allen anderen unterordnet — auch wenn sie eigentlich zuerst da wäre. Beides lässt sich in der Nähe der Kreuzung platzieren und rastet automatisch exakt auf den jeweiligen Kreuzungsarm ein.
